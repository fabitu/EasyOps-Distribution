# EasyOps Distribution

Repositório público de distribuição do EasyOps.

## Baixar o EasyOps

[**Baixar o instalador do EasyOps 1.0.0**](https://github.com/fabitu/EasyOps-Distribution/releases/download/easyops-v1.0.0/EasyOps-1.0.0-Setup.exe)

[Ver todos os arquivos da versão 1.0.0](https://github.com/fabitu/EasyOps-Distribution/releases/tag/easyops-v1.0.0)

Aqui ficam os catálogos de atualização e os GitHub Releases com os pacotes compilados e seus checksums SHA-256. O código-fonte não é publicado neste repositório.

- `catalog-stable.json`: versões estáveis.
- `catalog-preview.json`: versões de prévia.

Os pacotes são produzidos automaticamente pelo CI/CD do projeto EasyOps. Releases são imutáveis: uma correção sempre recebe uma nova versão.
